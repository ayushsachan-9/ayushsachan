Personal portfolio website for **Ayush Sachan** — Electronics & Communication Engineering (ECE) undergraduate working on embedded systems, IoT architectures, and hardware-software integration.

Live at: **[ayushsachan.in](https://ayushsachan.in)**

---

## ⚡ Featured Project: Sync-Space

A distributed multi-node home and industrial automation system engineered with:
- **Raspberry Pi Zero** edge gateway & local MQTT broker
- **ESP32** room microcontrollers driving optoisolated relays
- **mmWave Radar** detecting human respiration micro-movements to eliminate false shut-offs
- **433MHz RF Transceivers** for 100% offline failover when network connectivity drops
- **4 Dynamic Energy Saving Modes** (Normal, Smart Habit-Learning, Extreme Vampire Gating, Ultra-Low Power)
- Integrated safety telemetry (MQ-135 AQI, MQ-2 smoke/gas, flame detection, water tank management)

---

## 🛠️ Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS (Neutral Monochrome theme)
- **Icons**: Lucide React
- **Hosting**: Cloudflare Pages + Edge Worker Middleware

---

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev
```

To deploy updates to Cloudflare Pages:
```bash
npm run deploy
```
